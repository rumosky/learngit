### 总结

显示颜色提示

```shell
git config --global color.ui true
```

查看全部 Git 配置

```shell
git config --list
```

更新 Git 客户端（2.16.1 版本之后）

```shell
git update-git-for-windows
```

更新 Git 客户端（2.14.2 版本-2.16.1 版本）

```shell
git update
```

> 2.14.2 之前的版本请直接卸载 Git，然后下载新版后直接安装即可，Linux 系统直接运行，yum install git 即可（以 CentOS 为例）

查看 Git 版本

```bash
git --version
```
